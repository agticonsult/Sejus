## 2. Logic Chain

From the above observations, the step-by-step reasoning leads to the following implementation architecture:

1. **Scaffolding Foundation**:
   - Because `package.json`, `vite.config.js`, and `resources/views/app.blade.php` are missing, the project currently lacks the runtime environment to compile and serve Inertia.js + Vue 3 pages.
   - Creating `package.json` with `@inertiajs/vue3`, `vue`, `@vitejs/plugin-vue`, `laravel-vite-plugin`, `tailwindcss`, `postcss`, `autoprefixer`, and `lucide-vue-next` establishes standard Vue 3 Single File Component (SFC) bundling with Vite.

2. **Inertia Root & Entry Point**:
   - Creating `resources/views/app.blade.php` with `@inertia` and `@vite(['resources/css/app.css', 'resources/js/app.js'])` allows Laravel 11 to bootstrap Inertia responses.
   - Creating `resources/js/app.js` with `createInertiaApp` resolves pages dynamically from `./Pages/**/*.vue`.

3. **Design System & Accessibility Architecture**:
   - The design tokens in `styles.css` can be directly mapped into `resources/css/app.css` and `tailwind.config.js`.
   - The accessibility requirements (F36, F37, F38) demand three simultaneous features:
     - **Alto Contraste**: Toggles `.high-contrast` on `document.body` (background `#000000`, surface `#121212`, text `#ffffff`, border `#444444`, accent `#00ffff`). Meets WCAG 2.1 AAA contrast ratio >= 7:1.
     - **Escala de Fonte (A+)**: Modifies CSS custom property `--font-scale` to `1.18` (clamped between `1.00` and `1.50`), dynamically resizing typography via `calc(15px * var(--font-scale))`.
     - **Linguagem Fácil (*Linguagem Simplificada*)**: Toggles `.simplified-lang` class and activates reactive microcopy dictionary (transforming technical terms into plain Portuguese for low digital literacy).
   - Preferences must be persisted in `localStorage` (`conecta_high_contrast`, `conecta_font_zoom`, `conecta_simplified_lang`) and restored on page visits.

4. **Component & Page Decomposition**:
   - Layout: `resources/js/Layouts/AppLayout.vue` wrapping the top header, SEJUS flag badge, global search, accessibility toolbar, profile/role switcher, and sidebar navigation.
   - 8 Core Views in `resources/js/Pages/`:
     1. `Dashboard.vue`: KPI metric cards, attendance trends chart, 78 municipalities demand heatmap, and real-time activity feed.
     2. `Atendimento.vue`: Attendance queue list, call initiate button, WebRTC video grid, in-call chat, call duration timer, MOS telemetry signal meter, and notes/encaminhamento editor.
     3. `Oportunidades.vue`: Jobs and courses directory, filter by 78 ES municipalities, modality filter, affirmative action badge, and application modal.
     4. `Carteira.vue`: Digital credential card with SEJUS seal, masked CPF (LGPD), dynamic QR code rendering, and PDF download button (`/carteira/pdf`).
     5. `Geolocalizacao.vue`: Interactive regional grid of 78 ES municipalities (Metropolitana, Central, Rio Doce, Noroeste, Caparaó, Litoral Sul, Serrana), local CRAS/CREAS/SINE details, and service filters.
     6. `Prontuario.vue`: Egresso dossier, risk indicator, chronological timeline of psychosocial interventions, notes editor, and new intervention entry modal.
     7. `Relatorios.vue`: Executive BI dashboard, regional filters, municipal summary table, export CSV/PDF, and audit log table.
     8. `SegurancaLgpd.vue`: RBAC permissions matrix, privacy/consent management, AES-256 encryption status, and immutable audit trail inspector.
     9. `ValidarCarteira.vue`: Public document validation view (`/validar-carteira/{token}`).
   - Shared Components in `resources/js/Components/`:
     - `AccessibilityToolbar.vue`: Toggles for Contrast, Font Scaling (+18%), and Easy Language.
     - `ChartBar.vue` & `ChartDonut.vue`: HTML5 Canvas chart renderers.
     - `QrCodeDisplay.vue`: SVG/Canvas QR Code renderer with cryptographic token.
     - `VideoModal.vue`: WebRTC video calling modal with media controls.
   - WebRTC Engine in `resources/js/Services/webrtc.js`:
     - Manages `WebSocket` signaling connection to FastAPI (`/ws/room/{roomId}`).
     - Manages `RTCPeerConnection` with STUN/TURN ICE configuration.
     - Performs real-time telemetry sampling (`getStats()`) to compute ITU-T G.107 MOS score, RTT, jitter, and packet loss.

### 4.5 Proposed `resources/js/app.js`
```javascript
import { createApp, h } from 'vue';
import { createInertiaApp, Head, Link } from '@inertiajs/vue3';
import { resolvePageComponent } from 'laravel-vite-plugin/inertia-helpers';
import '../css/app.css';

const appName = window.document.getElementsByTagName('title')[0]?.innerText || 'CONECTA EGRESSO';

createInertiaApp({
    title: (title) => title ? `${title} - ${appName}` : appName,
    resolve: (name) => resolvePageComponent(`./Pages/${name}.vue`, import.meta.glob('./Pages/**/*.vue')),
    setup({ el, App, props, plugin }) {
        return createApp({ render: () => h(App, props) })
            .use(plugin)
            .component('Head', Head)
            .component('Link', Link)
            .mount(el);
    },
    progress: {
        color: '#0284c7',
        showSpinner: true,
    },
});
```

## 5. Verification Method

To independently verify the frontend scaffolding and build readiness:

1. **Inspect Configuration Files**:
   - Check presence of `package.json`, `vite.config.js`, `tailwind.config.js`, `postcss.config.js`.
   - Verify `resources/views/app.blade.php` contains `@inertia` and `@vite`.
2. **Execute Build**:
   ```bash
   npm install
   npm run build
   ```
   - Build output must compile without errors into `public/build/manifest.json` and bundled assets.
3. **Execute E2E Frontend Tests**:
   ```bash
   python -m unittest tests_e2e/tier1_features/test_f34_f47_frontend_views.py
   python -m unittest tests_e2e/tier2_boundaries/test_frontend_a11y_limits.py
   python -m unittest tests_e2e/tier3_combinations/test_a11y_multimode_states.py
   ```
4. **Invalidation Conditions**:
   - Any failure in Vite bundle compilation (`npm run build`).
   - Failure to toggle `.high-contrast` class or `--font-scale: 1.18`.
   - Broken Inertia page resolution for any of the 8 core views or public validator view.
